# Evaluation Guide: First Frame Images

本指南用于评估**首帧图**——视频生成前为特定 shot 生成的起始画面。

首帧图与参考图的目的完全不同：
- **参考图**：建立身份锚点，要求白背景、全身、居中
- **首帧图**：定义视频开场构图，是一个**场景画面**，需要角色站位、环境氛围、镜头角度

---

## 评估流程

1. 调用方会提供：首帧图路径、shot 信息（shot_type / angle / movement / intent）、出镜角色及其参考图、场景描述。
2. 用 **AnalyzeImage** 查看首帧图。images 中同时传入**首帧图**和**出镜角色的参考图**（各自标注 label），prompt 要求 VLM 按下方 checklist 检查各项，并对比角色参考图判断角色是否可辨认。
3. 按下方 checklist 逐项检查。
4. 输出结构化报告。

---

## Checklist

| 检查项 | PASS 标准 | 常见 FAIL 原因 |
|--------|----------|---------------|
| **角色可辨认** | 出镜角色与参考图中的角色在外貌、服装上一致，可以被识别 | 角色面部/体型/服装与参考图明显不符 |
| **角色完整** | 根据 shot_type 判断：wide/full 需要全身；medium 至少半身以上；close_up 允许局部 | wide shot 但角色被截断 |
| **站位/构图合理** | 角色位置符合 shot intent 描述（如"两人对峙"应两人面对面） | 角色位置不合理（该面对面的却背对背） |
| **镜头角度匹配** | 画面视角与 angle 一致（eye_level / low_angle / high_angle / bird_eye） | 要求 low_angle 但实际是平视 |
| **场景氛围匹配** | 背景环境与 location state 描述一致（森林/室内/天气/光照） | 场景类型或氛围完全不符 |
| **无多余角色** | 只有预期出镜的角色在画面中 | 出现了不该出现的人物 |
| **画面质量** | 无明显变形、伪影、模糊 | 人物变形、面部崩坏 |

---

## 判定规则

### 检查项分级

| 检查项 | 级别 | 说明 |
|--------|------|------|
| 角色可辨认 | **关键** | 角色与参考图差异太大（换脸、换性别、体型完全不同）不可接受 |
| 角色完整 | **关键** | wide/full shot 中角色被截断不可接受 |
| 站位/构图合理 | **关键** | 该出现的角色缺失、人数不对不可接受 |
| 场景氛围匹配 | **关键** | 场景类型完全错误（森林变城市）不可接受 |
| 镜头角度匹配 | **次要** | 角度略有偏差（low_angle 接近 eye_level）可接受 |
| 无多余角色 | **次要** | 背景中有模糊人影可接受；前景出现明确的多余角色为关键 FAIL |
| 画面质量 | **次要** | 轻微模糊可接受；严重变形/面部崩坏升级为关键 FAIL |

### 从单项到结论的判定

| 情况 | 结论 |
|------|------|
| 所有检查项 PASS | **PASS** |
| 有任意**关键项** FAIL | **FAIL**（需重新生成） |
| 关键项全部 PASS，仅**次要项**有问题 | **ACCEPTABLE**（不重新生成，记录瑕疵） |

### 其他原则

- **不要求白背景**：首帧图是场景画面，背景应该是实际的故事场景。
- **给出可操作的修改建议**：FAIL 时指出具体问题（如"角色面部与参考图不一致，建议加强参考图权重"、"缺少第二个角色，建议在 prompt 中明确提及两人站位"）。
