# Evaluation Guide: Reference Images

本指南用于评估**实体参考图**（Character / Location / Prop）和**状态参考图**（CharacterAppearance / LocationState / PropState）。

---

## 评估流程

1. 调用方会提供：图片路径列表、每张图的类型（character / location / prop / appearance / location_state / prop_state）、对应的描述（`fixed_traits` 或 `visual`/`appearance`）、以及项目目标风格（`style_prefix`）。
2. 用 **AnalyzeImage** 分析图片，在 prompt 中传入 checklist 检查项和调用方提供的描述供 VLM 比对。
   - **实体图**：每张单独调用，images 传一张，prompt 要求检查对应类型的各项。
   - **状态图**：images 同时传入**实体基础图**和**状态图**两张（分别标注 label），prompt 要求 VLM 对比两图检查身份一致性和状态差异。
3. 根据 AnalyzeImage 返回的分析结果，按下方对应类型的 checklist 逐项判定 PASS / FAIL / ACCEPTABLE。
4. 输出结构化报告。

---

## Checklist

### Character 实体图 & CharacterAppearance 状态图

| 检查项 | PASS 标准 | 常见 FAIL 原因 |
|--------|----------|---------------|
| **全身可见** | 头顶到脚底完整可见，无截断 | 脚被裁切、只有半身 |
| **纯白背景** | 背景为纯白或接近纯白，无场景元素 | 有阴影、渐变、场景环境、黑色背景 |
| **居中构图** | 人物居中，无明显偏移 | 人物偏左/偏右 |
| **单一视图** | 只有一个角度的全身像 | 生成了多视图 character sheet（正面+侧面+细节） |
| **特征匹配** | 与提供的描述中的关键特征一致 | 性别、年龄、体型、种族等明显不符 |
| **风格匹配** | 画面风格与调用方提供的 `style_prefix` 一致 | style_prefix 要求写实但生成了卡通；要求水彩但生成了 3D 渲染 |
| **无光影污染** | 无 cinematic lighting、体积光、强烈阴影 | 背景有光晕、雾气、明暗渐变 |
| **无边框** | 图片边缘无白色或其他颜色的边框/画框 | 图片四周有白色边框、装饰性画框 |

**CharacterAppearance 状态图额外检查**：
- **状态差异体现**：与实体基础图相比，服装/发型/体态等变化是否在画面中可见（如"斗篷歪斜"是否确实歪斜）
- **身份一致性**：角色的基本身份特征（脸型、体型、种族）是否与实体图保持一致

### Location 实体图 & LocationState 状态图

| 检查项 | PASS 标准 | 常见 FAIL 原因 |
|--------|----------|---------------|
| **无角色出现** | 画面中没有人物、角色、人影 | 出现了人形轮廓 |
| **场景匹配** | 与描述的场景类型一致（森林/城市/室内等） | 场景类型完全不符 |
| **氛围一致** | 光照、天气、季节与描述一致 | 描述晴天但生成了阴暗场景 |
| **无边框** | 图片边缘无边框/画框 | 图片四周有白色边框、装饰性画框 |

**LocationState 状态图额外检查**：
- **状态变化体现**：与实体基础图相比，光照/天气/氛围变化是否可见
- **场景一致性**：是否仍然是同一个场景，只是氛围发生了变化

### Prop 实体图 & PropState 状态图

| 检查项 | PASS 标准 | 常见 FAIL 原因 |
|--------|----------|---------------|
| **纯白背景** | 背景纯白 | 有阴影或场景 |
| **居中特写** | 道具居中、清晰可辨 | 太小或被其他元素遮挡 |
| **物品匹配** | 与描述的道具外观一致 | 形状、颜色、材质明显不符 |
| **无边框** | 图片边缘无边框/画框 | 图片四周有白色边框、装饰性画框 |

## 判定规则

### Character / CharacterAppearance 检查项分级

| 检查项 | 级别 | 说明 |
|--------|------|------|
| 全身可见 | **关键** | 脚截断、半身均不可接受 |
| 纯白背景 | **关键** | 背景整体灰色渐变、场景元素、黑/灰背景不可接受。角色脚下轻微接触阴影可接受（不算 FAIL） |
| 单一视图 | **关键** | 多视图 character sheet 不可接受 |
| 特征匹配（关键特征：性别、种族、体型、物种） | **关键** | 关键特征不符不可接受 |
| 风格匹配（与 style_prefix 一致） | **关键** | 风格大类不符（如要求写实却生成卡通）不可接受。同一风格大类内的细微差异可接受 |
| 无光影污染 | **次要** | 轻微阴影可接受，明显光晕/雾气/体积光不可接受 |
| 无边框 | **关键** | 图片边缘有任何边框/画框均不可接受 |
| 居中构图 | **次要** | 轻微偏移可接受 |
| 特征匹配（次要特征：发色深浅、衣服纹理细节） | **次要** | 细节偏差可接受 |
| 白衣白背景融合 | **次要** | 边缘不清晰可接受，但需在建议中提出 |

**CharacterAppearance 额外项**：
| 检查项 | 级别 |
|--------|------|
| 身份一致性（与实体图的脸型/体型/种族） | **关键** |
| 状态差异体现（服装/发型变化是否可见） | **次要** |

### Location / LocationState 检查项分级

| 检查项 | 级别 |
|--------|------|
| 场景匹配（场景类型） | **关键** |
| 无角色出现 | **关键** |
| 无边框 | **关键** | 图片边缘有任何边框/画框均不可接受 |
| 氛围一致（光照/天气/季节） | **次要** |

**LocationState 额外项**：
| 检查项 | 级别 |
|--------|------|
| 场景一致性（与实体图是否同一场景） | **关键** |
| 状态变化体现（光照/天气变化是否可见） | **次要** |

### Prop / PropState 检查项分级

| 检查项 | 级别 |
|--------|------|
| 纯白背景 | **关键** |
| 物品匹配（形状、类型） | **关键** |
| 无边框 | **关键** | 图片边缘有任何边框/画框均不可接受 |
| 居中特写 | **次要** |
| 物品匹配（颜色、材质细节） | **次要** |

### 从单项到结论的判定

| 情况 | 结论 |
|------|------|
| 所有检查项 PASS | **PASS** |
| 有任意**关键项** FAIL | **FAIL**（需重新生成） |
| 关键项全部 PASS，仅**次要项**有问题 | **ACCEPTABLE**（不重新生成，记录瑕疵） |

### 其他原则

- **修改建议限定在 prompt 层面**：FAIL 时指出 prompt 中可能的问题和具体的措辞修改方向（如"去掉 cinematic lighting"、"prompt 开头加 full-body standing figure on plain white background"、"prompt 超过 60 词需精简"）。**不要给出分辨率、色彩空间、画面比例等技术参数建议**——这些由生成规范决定，不在评估范围内。
- **无光影污染的边界**：轻微地面阴影（角色脚下的投影）算 ACCEPTABLE；背景整体灰色渐变、雾气、光晕算关键项 FAIL（归入"纯白背景"FAIL）。

## 输出格式

```
## 参考图评估报告

### 总览
- 总计: N 张
- PASS: X 张
- FAIL: Y 张（需重新生成）
- ACCEPTABLE: Z 张（有瑕疵但可接受）

### 逐张结果

#### {image_id} ({entity_type})
- 路径: {path}
- 描述: {调用方提供的描述摘要}
- 全身可见: PASS / FAIL — {简要说明}
- 纯白背景: PASS / FAIL — {简要说明}
- 居中构图: PASS / FAIL
- 单一视图: PASS / FAIL
- 特征匹配: PASS / FAIL — {哪些特征不符}
- 无光影污染: PASS / FAIL — {有什么光影问题}
- **结论: PASS / FAIL / ACCEPTABLE**
- 修改建议: {具体的 prompt 修改建议，如 "去掉 cinematic lighting"、"prompt 开头加 full-body standing figure on plain white background"}

...

### FAIL 图片汇总
| 图片 ID | 类型 | 失败项 | 修改建议 |
|---------|------|--------|---------|
| ... | ... | ... | ... |
```

**注意**：Location 图不需要检查"全身可见""纯白背景""居中构图""单一视图""无光影污染"这些项，只检查 Location 专属的检查项。Prop 图不需要检查"全身可见""单一视图"。根据类型输出对应的检查项即可。
