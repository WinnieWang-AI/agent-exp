Manage video project directory structure and metadata.

**Actions:**

- `init`: Create a new video project with standard directory structure (assets/clips, assets/images, assets/audio, output) and placeholder files (script.json, storyboard.json, characters.json, project.json).
- `status`: Show the current state of a project including metadata and asset counts.
- `update_metadata`: Update the project.json metadata file with new key-value pairs.

Always init a project before starting video creation work to keep assets organized.
